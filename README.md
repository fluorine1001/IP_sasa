# 작은 로켓의 큰 모험

지표 발사, 관성, 유한한 추진과 관측 기록을 이용하는 2D 로켓 퍼즐입니다. 개발 저장소는 [IP_sasa](https://github.com/fluorine1001/IP_sasa)입니다. 미래 궤도와 무료 예행 비행은 제공하지 않습니다.

## 실행

Node.js 24를 설치한 뒤 저장소 폴더에서 실행합니다.

```sh
npm ci
npm run dev
```

게임: http://127.0.0.1:5173/

개발용 제작: http://127.0.0.1:5173/?editor=1

```sh
npm run format
npm run verify
npx playwright install chromium
npm run test:e2e
npm run build
npm run preview
```

제작 모듈과 파일 저장 API는 개발 서버에서만 제공됩니다. 결과물은 `dist/`입니다. 현재는 데스크톱 브라우저 게임이며 Steam 배포용 네이티브 패키징은 포함하지 않습니다.

## 플레이

‘탐사 시작’은 다음 미완료 임무로, ‘스테이지 선택’은 게시판으로 갑니다. 도움말과 설정은 독립 화면입니다.

- 로켓에서 끌어 첫 추진을 정하고, 주황색 손잡이로 이어서 조절합니다. 지정한 행성·위성의 지표에서 출발합니다. 조준 중 시야 이동·확대·창 크기 변경은 조준을 끝내고 마지막 추진값을 유지합니다.
- 기본 추진 모델의 방향키는 유한한 수정 추진을 사용하고 B는 그 예산으로 제동합니다.
- 연료 모델에서는 좌우 방향키가 엔진 방향, 상하가 스로틀입니다. E는 점화·정지, J는 단 분리, Tab은 분리한 부스터로 조작 대상을 바꿉니다.
- 2·3은 중력·속력 부표를 방출합니다. 부표는 현재 위치와 속도를 이어받습니다.
- Space는 정지·재개, WASD·휠·가운데 버튼은 카메라 이동·확대입니다. C로 로켓 추적에 돌아갑니다.
- ‘비행 종료’로 도중에 끝내고 같은 스테이지에서 기록을 보고 재도전합니다. 발사 기회는 소비되며, 모두 쓰면 해당 스테이지를 새로 시작할 수 있습니다. 게시판 이동은 ‘임무 나가기’로 직접 선택합니다.
- 모든 실제 발사는 같은 환경에서 진행합니다. 실패한 시도도 실험 카드에 남으며, 방향을 고정하고 첫 추진 세기만 바꾸어 비교할 수 있습니다. 미래 결과는 보이지 않습니다.
- 지난 실제 궤적을 우클릭해 수정 추진을 예약하거나, 기록의 실제 조작을 다음 계획으로 복사합니다. 시간 눈금에서 로켓과 움직이는 목표의 과거 위치를 비교합니다.

각 스테이지는 독립적입니다. 관측·궤적·추진 계획·부표·분리체·연료·발사 기회는 다른 스테이지로 전달되지 않으며, 새로 입장하면 초기화됩니다. 같은 스테이지의 재도전은 동일한 환경이며 실제 관측·경로·조작을 누적합니다. 첫 추진 세기만 조절하거나 이전 조작을 복사하고 시간별 경로를 비교해 풀이를 좁힙니다.

설정과 완료 기록은 현재 브라우저에 저장됩니다. 플레이 로그를 서버로 보내지 않습니다. 이미지와 효과음은 코드로 제작한 임시 자산입니다.

## 임무를 조건으로 만듭니다

목표 엔진에 궤도·착륙·스윙바이별 분기가 없습니다. 비행체와 기준 대상을 고르고 물리량·수식·순간 기록·구간 통계를 비교한 다음 AND/OR·순서·유지·사건으로 조합합니다. 새 임무 이름을 엔진에 등록할 필요가 없습니다.

8개 소스 스테이지는 이 시스템을 사용하는 예시입니다. 임무 범위를 이 8개로 제한하지 않습니다. 새로운 **물리 현상 자체**는 물리 엔진과 조회 모듈에 확장해야 합니다.
