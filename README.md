# 작은 로켓의 큰 모험

지표 발사, 관성, 유한한 추진과 관측 기록을 이용하는 2D 로켓 퍼즐입니다. 개발 저장소는 [IP_sasa](https://github.com/fluorine1001/IP_sasa)입니다. 미래 궤도와 무료 예행 비행은 제공하지 않습니다.

## 실행

Node.js 24를 설치한 뒤 저장소 폴더에서 실행합니다.

```sh
npm ci
npm run dev
```

게임: http://127.0.0.1:5173/

개발용 제작: http://127.0.0.1:5173/?editor=1

```sh
npm run format
npm run verify
npx playwright install chromium
npm run test:e2e
npm run build
npm run preview
```

제작 모듈과 파일 저장 API는 개발 서버에서만 제공됩니다. 결과물은 `dist/`입니다. 현재는 데스크톱 브라우저 게임이며 Steam 배포용 네이티브 패키징은 포함하지 않습니다.

## 플레이

‘탐사 시작’은 다음 미완료 임무로, ‘스테이지 선택’은 게시판으로 갑니다. 도움말과 설정은 독립 화면입니다.

- 발사 전에 로켓에서 끌어 첫 출력·방향을 정합니다. 출력계는 지면을 떠날 힘과 현재 출력의 연료 지속 시간을 보여 줍니다.
- ‘비행 계획 편집’에서 시각별 엔진 출력·끄기·방향·단 분리·장비 방출을 예약합니다. 아이콘을 끌거나 시각을 입력합니다. 같은 시각의 명령은 목록 순서대로 실행됩니다.
- 발사하면 계획은 잠깁니다. 일시정지 중에도 추진·단 분리·장비 방출을 추가하지 않습니다. 진행 바의 아이콘과 시간 눈금으로 실제 실행을 확인합니다.
- 로켓은 실제 단별 몸체로 구성됩니다. 분리하면 위 로켓이 짧아지고 부스터가 따로 움직이며 충돌 몸체도 바뀝니다. 다음 단 엔진은 따로 점화를 예약해야 합니다.
- Space는 정지·재개, WASD·휠·가운데 버튼은 카메라 이동·확대입니다. C로 로켓 추적에 돌아갑니다. 비행체 추적 전환은 카메라 대상만 바꿉니다.
- ‘비행 종료’로 중단하고 관측을 다음 계획에 반영합니다. 실제 비행 기록에서 각 시도를 다시 재생할 수 있습니다. 다시보기는 당시 계획·연료·분리·움직이는 천체를 읽으며 다음 계획과 격리됩니다.
- 다시보기 로켓은 살짝 투명하며 약한 화면 잡음이 있습니다. 진행 바를 끌어 기록된 시각으로 이동하고 재생·정지합니다. 기본 카메라는 로켓 추적입니다.
- 발사 기회를 모두 쓰면 해당 스테이지를 새 도전으로 시작할 수 있습니다. 환경과 관측 기록은 같은 스테이지 안에서 유지됩니다. 게시판 이동은 ‘임무 나가기’로 직접 선택합니다.

각 스테이지는 독립적입니다. 관측·궤적·추진 계획·부표·분리체·연료·발사 기회는 다른 스테이지로 전달되지 않으며, 새로 입장하면 초기화됩니다. 같은 스테이지의 재도전은 동일한 환경이며 실제 관측·경로·조작을 누적합니다. 첫 추진 세기만 조절하거나 이전 조작을 복사하고 시간별 경로를 비교해 풀이를 좁힙니다.

설정과 완료 기록은 현재 브라우저에 저장됩니다. 플레이 로그를 서버로 보내지 않습니다. 로켓 이미지는 자체 제작한 캔버스 아트이며 동일 렌더러로 내보낸 투명 PNG가 public/assets/rockets에 있습니다. 효과음도 코드로 제작합니다. 실제 비행 기록은 현재 스테이지 세션 안에 보관합니다.

## 임무를 조건으로 만듭니다

목표 엔진에 궤도·착륙·스윙바이별 분기가 없습니다. 비행체와 기준 대상을 고르고 물리량·수식·순간 기록·구간 통계를 비교한 다음 AND/OR·순서·유지·사건으로 조합합니다. 새 임무 이름을 엔진에 등록할 필요가 없습니다.

8개 소스 스테이지는 이 시스템을 사용하는 예시입니다. 임무 범위를 이 8개로 제한하지 않습니다. 새로운 **물리 현상 자체**는 물리 엔진과 조회 모듈에 확장해야 합니다.
