# 디자인 시스템

색·글자·간격·모양은 `src/ui/tokens.css` 한 곳에서 정합니다. 패널·버튼·제목의 최종 모양은 `src/ui/system.css`가 정합니다. 정보 그림은 `src/ui/figures.ts`·`figures.css`의 부품을 씁니다. 캔버스 그림은 `src/ui/palette.ts`(토큰과 같은 값, 테스트가 일치를 검사)와 `src/render/fonts.ts`를 씁니다.

## 레퍼런스: 산소 미포함(Oxygen Not Included)

그 게임의 UI가 복잡한 시뮬레이션을 다루면서도 잘 읽히는 이유를 기준으로 삼습니다.

- **재질은 하나.** 모든 패널이 같은 어두운 청회색 면(`--panel`) + 진한 테두리(`--panel-edge`)입니다. 화면마다 재질을 바꾸지 않으므로 사람은 한 번 익힌 읽기 방식을 어디서나 씁니다.
- **흰 글씨, 굵게.** 패널 위 글자는 흰색(`--c-text`) 또는 밝은 회색(`--n-200`)이고 굵기는 600 이상입니다.
- **제목과 큰 숫자는 둥근 굵은 서체.** `--font-display`(주아, OFL). 본문은 Pretendard.
- **색은 뜻 하나씩, 진하게.** 칠한 면은 의미가 있을 때만 씁니다.
- **아이콘이 먼저, 글은 짧게.** 줄마다 아이콘 + 짧은 이름 + 굵은 숫자, 그리고 막대 게이지.
- **도톰한 버튼.** 둥근 모서리, 2px 테두리, 안쪽 아랫단(`--bevel`)으로 누를 수 있음이 보입니다.

## 반드시 지키는 가독성 규칙

1. **작은 글씨로 설명하지 않는다.** 글자 크기의 바닥은 `--fs-1`(15px)입니다. 부가 설명이 필요하면 작게 깔지 말고 아이콘·그림으로 바꾸거나, 눌렀을 때 같은 크기로 펼칩니다.
2. **대비.** 24px 미만 글자는 배경과 4.5:1 이상, 큰 글자·아이콘·게이지 눈금·지도 선은 3:1 이상. 로고와 장식 글자도 예외 없습니다.
3. **허용 짝(전경/배경).** 이 표 밖의 조합은 쓰기 전에 대비를 재고 표에 추가합니다.

| 배경 | 글자·아이콘 |
| --- | --- |
| `--panel`, `--panel-raised`, `--panel-sunk`, `--n-900`(지도) | `--c-text`(흰색), `--n-200`, `--amber-400`, `--green-400`, `--red-200`, `--sky-200`, `--pink-200`, `--yellow-400` |
| `--amber-400`(주 행동 버튼) | `--n-950` |
| `--pink-400`(선택됨) | `--c-text` |
| `--n-600`(버튼) | `--c-text` |
| `--green-400`, `--yellow-400` 칠한 면 | `--n-950` |

`--n-300` 이하 어두운 회색은 글자에 쓰지 않습니다(테두리·눈금 전용).

4. **지도 위 글자**는 어두운 테두리(halo)를 두르고 15px 이상, 굵게.
5. **검사.** 개발 서버를 켠 뒤 `AUDIT_URL=http://127.0.0.1:5173/ node scripts/readability-audit.mjs desk`(또는 `phone`). 15px 미만이거나 대비 미달인 보이는 글자를 모두 `test-results/readability/`에 남깁니다. 결과가 0건이어야 합니다. SVG 안의 글자는 스크린숏으로 확인합니다.

## 금지 요소

- 광택 구슬·원형 그라데이션 입체 단추나 메달, 나사·리벳·금속판 질감
- 아래로 툭 떨어지는 단색 그림자(`0 4px 0 #000` 형태)
- 기울어진 라벨·도장, 외곽선이나 그림자를 두른 글자
- 튀는 움직임, 반복 장식 애니메이션
- 밝은 종이 위 흐린 글씨, 어두운 면 위 어두운 회색 글씨

## 색의 뜻

| 토큰 | 뜻 |
| --- | --- |
| `--amber-*` | 지금 누를 주 행동 하나, 예약(계획한 조작) |
| `--pink-*` | 선택됨, 지금 보고 있는 것 |
| `--green-*` | 충족, 성공 |
| `--red-*` | 실패, 위험, 한계 초과 |
| `--sky-*` | 정보, 계산 도구(궤도 계산기) |
| `--yellow-*` | 지도 위 임무 목표 |
| `--cmd-*` | 타임라인 조작 칩과 기체 단 표시만 |

## 그림으로 말하기

정보는 먼저 그림으로, 숫자는 그림 옆 보조로.

- 기체 → 단 옆모습(`rocketSide`), 단별 Δv 막대, 이륙 추력 대 무게 게이지, 점화 횟수 아이콘(`pips`)
- 천체 → 상대 크기 원판(`bodyDisc`)
- 궤도 계산 → 궤도 축소도(`orbitFigure`), 속력 눈금(원궤도·탈출)
- 빗나감 → 목표 고리와 최근접 점(`missFigure`), 원인이 된 조작 바로가기
- 메달 → 평면 휘장(`medalBadge`)
- 원래 표는 "숫자로 보기" 접힘 안에 둡니다.

## 움직임과 소리

- 실제 사건(발사·분리·접지·패널 열림)에만 150–250ms로 짧게 반응합니다.
- 소리는 기계음: 엔진·분리·접지는 낮고 둔한 소리, 인터페이스는 짧은 딸깍 소리.
