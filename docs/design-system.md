# 디자인 시스템

게임 화면의 색·글자·간격·모양은 `src/ui/tokens.css` 한 곳에서 정합니다. 재질(계기·문서·조작)은 `src/ui/system.css`가 최종으로 정합니다. 정보 그림은 `src/ui/figures.ts`·`figures.css`의 부품을 씁니다. 캔버스 그림은 `src/ui/palette.ts`(토큰과 같은 값, 테스트가 일치를 검사)와 `src/render/fonts.ts`를 씁니다.

## 콘셉트: 비행역학 관제실

플레이어는 관제실의 비행역학 담당자입니다. 화면은 그가 보는 **계기 화면**과 그가 받는 **기술 문서**로만 이루어집니다. 장난감·만화·아케이드의 말투를 쓰지 않습니다. 기준은 "실제 관제실 장비 화면과 NASA 비행 계획 문서를 현대적으로 정돈하면 이렇게 보이겠다"입니다.

## 금지 요소

아래는 플래시 게임처럼 보이게 하는 장식이며 어떤 화면에도 쓰지 않습니다.

- 광택 구슬·원형 그라데이션으로 만든 입체 단추나 메달
- 나사·리벳, 금속판 질감, 줄무늬 위험 테이프
- 두꺼운 검은 테두리(2px 이상), 아래로 툭 떨어지는 단색 그림자(`0 4px 0 #000` 형태)
- 기울어진 라벨·도장(회전 변형), 외곽선이나 그림자를 두른 글자
- 튀거나 커졌다 줄어드는 움직임, 반복 장식 애니메이션
- 모눈종이 배경(그래프의 측정 영역 안에서만 가는 격자 허용)
- 이모지, 만화 효과음

## 재질

| 재질 | 쓰는 곳 | 모양 |
| --- | --- | --- |
| 계기 | 지도 위에 늘 떠 있는 패널(임무 카드, 계기판, 타임라인) | 어두운 유리 `--c-glass`, 1px 밝은 가는 선, 부드러운 그림자, 모서리 `--r-md` |
| 문서 | 읽는 것(브리핑, 결과, 조작 팝업, 비행 일지, 설정) | 밝은 종이 `--c-doc`, 1px 어두운 가는 선, 모서리 `--r-md`, 격자 없음 |
| 조작 | 버튼·입력 | 평평한 면, 1px 선, 모서리 `--r-sm`; 누르면 1px 내려감; 주 행동만 호박색으로 채움 |

깊이는 그림자 토큰 `--sh-1~3`만 씁니다. 선은 `--edge`(어두운 면 위 문서 선)와 `--edge-light`(계기 유리의 밝은 선) 둘뿐입니다.

## 그림으로 말하기

글이나 표로만 된 설명은 대부분 읽히지 않습니다. 정보는 먼저 그림으로, 숫자는 그림 옆 보조로 보여 줍니다.

- 기체 → 단을 이어 붙인 옆모습 그림(`rocketSide`), 단별 Δv 막대, 추력 대 무게 게이지(1.0 이륙선), 점화 횟수 아이콘(`pips`)
- 천체 → 상대 크기 원판(`bodyDisc`)과 대기 고리
- 궤도 계산 → 기준 천체와 궤도 축소도(`orbitFigure`), 속력 눈금(원궤도·탈출 표시)
- 목표 근접·빗나감 → 목표 고리와 최근접 점(`missFigure`), 목표 범위 위의 측정값 게이지(`meter`)
- 메달 → 선으로 그린 평면 휘장(`medalBadge`); 받은 것은 신호색, 못 받은 것은 점선
- 원래 표는 "숫자로 보기" 접힘 안에 남겨 둡니다.

## 색의 뜻

| 토큰                       | 뜻                                 | 쓰지 않는 곳                |
| -------------------------- | ---------------------------------- | --------------------------- |
| `--c-accent` (호박색)      | 지금 누를 주 행동 하나             | 장식, 경고                  |
| `--c-ok` (초록)            | 충족, 성공, 켜짐                   | 단 색                       |
| `--c-danger` (빨강)        | 실패, 위험, 한계 초과              | 주 행동                     |
| `--c-info` (하늘)          | 정보, 계산 도구(궤도 계산기)       | 목표                        |
| `--c-target` (노랑)        | 지도 위 임무 목표                  | 버튼                        |
| `--cmd-*`                  | 타임라인 조작 칩과 기체 단 표시만  | 그 밖의 모든 곳             |
| `--c-doc*` (종이)          | 읽는 문서                          | 늘 떠 있는 계기판·버튼 영역 |

## 글자

- 한 가지 글꼴: Pretendard(앱에 포함, OFL). 숫자는 고정폭 숫자.
- 크기는 `--fs-1`(13px)부터 `--fs-6`(44px)까지 여섯 단계. 13px 미만은 쓰지 않습니다.
- 패널 안 구획 이름은 `--fs-1` 중간 굵기의 흐린 글자와 가는 선 한 줄. 대문자 흉내·띠지 라벨은 쓰지 않습니다.
- 강조는 굵기와 크기로만 합니다. 글자에 그림자·외곽선을 두르지 않습니다.
- 설정의 "글자·버튼 크기"가 `--ui-scale`로 모든 단계를 함께 키웁니다.

## 움직임과 소리

- 실제 사건(발사·분리·접지·패널 열림)에만 150–250ms로 짧게 반응합니다. 크기 튐 없음.
- 소리는 기계음: 엔진·분리·접지는 낮고 둔한 소리, 인터페이스는 짧은 딸깍 소리.

## 가독성 기준

- 글자와 배경의 대비: 24px 미만(굵게 18.66px 미만)은 **4.5:1 이상**, 그보다 크면 **3:1 이상**.
- 지도(캔버스) 위의 글자는 반드시 어두운 받침 위에 놓습니다.
- 숫자에는 단위와 비교 기준을 붙입니다("0.30 / 한계 0.27 u/s").
- 검사: 개발 서버를 켠 뒤 `AUDIT_URL=http://127.0.0.1:5173/ node scripts/readability-audit.mjs desk`(또는 `phone`).
