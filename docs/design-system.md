# 디자인 시스템

게임 화면의 색·글자·간격·모양은 `src/ui/tokens.css` 한 곳에서 정합니다. 새 화면은 `src/ui/components.css`의 구성 요소를 씁니다. 화면 배치는 `src/ui/screens.css`에 둡니다. 캔버스 그림은 `src/ui/palette.ts`(토큰과 같은 값, 테스트가 일치를 검사)와 `src/render/fonts.ts`를 씁니다.

## 색의 뜻

| 토큰                       | 뜻                                 | 쓰지 않는 곳                 |
| -------------------------- | ---------------------------------- | ---------------------------- |
| `--c-accent` (노랑·호박색) | 지금 누를 주 행동 하나             | 장식, 경고                   |
| `--c-ok` (초록)            | 충족, 성공, 켜짐                   | 단 색                        |
| `--c-danger` (빨강)        | 실패, 위험, 한계 초과              | 주 행동                      |
| `--c-info` (하늘)          | 정보, 계산 도구(궤도 계산기)       | 목표                         |
| `--c-target` (노랑)        | 지도 위 임무 목표                  | 버튼                         |
| `--cmd-*`                  | 타임라인 조작 칩과 기체 단 표시만  | 그 밖의 모든 곳              |
| `--c-doc*` (종이)          | 읽는 문서: 브리핑, 결과, 비행 일지 | 늘 떠 있는 계기판·버튼 영역 |

## 글자

- 한 가지 글꼴: Pretendard(앱에 포함, OFL). 숫자는 고정폭 숫자.
- 크기는 `--fs-1`(13px)부터 `--fs-6`(44px)까지 여섯 단계. 13px 미만은 쓰지 않습니다.
- 설정의 "글자·버튼 크기"가 `--ui-scale`로 모든 단계를 함께 키웁니다.

## 가독성 기준

- 글자와 배경의 대비: 24px 미만(굵게 18.66px 미만)은 **4.5:1 이상**, 그보다 크면 **3:1 이상**.
- 지도(캔버스) 위의 글자는 반드시 어두운 받침 위에 놓습니다.
- 숫자에는 단위와 비교 기준을 붙입니다("0.30 / 한계 0.27 u/s").
- 검사: 개발 서버를 켠 뒤 `AUDIT_URL=http://127.0.0.1:5173/ node scripts/readability-audit.mjs desk`(또는 `phone`). 화면 14개의 보이는 글자를 모두 재고 기준 미달을 `test-results/readability/`에 남깁니다. SVG 안의 글자는 배경을 읽지 못해 거짓 경고가 날 수 있으니 스크린숏으로 확인합니다.

## 구성 요소

`ui-btn`(`primary`·`ghost`·`danger`, `sm`·`lg`), `ui-panel`, `ui-doc`, `ui-eyebrow`, `ui-h1~3`, `ui-body`, `kbd`, `ui-stat`, `ui-table`, `ui-meter`, `ui-dialog`.

## 문자열

`src/i18n/ko.ts`에 `화면.요소` 키로 둡니다. 화면에서는 `t('settings.title')`처럼 씁니다. 다른 언어는 같은 키의 표를 하나 더 만들면 됩니다. 아직 옮기지 않은 화면의 문자열은 코드 안에 남아 있습니다.
