# 디자인 시스템

생김새는 **역할**로 정한다. 화면 코드는 요소에 역할을 줄 뿐 색·테두리·그림자를 직접 쓰지 않는다.

| 파일                | 담당                                                                                 | 층           |
| ------------------- | ------------------------------------------------------------------------------------ | ------------ |
| `src/ui/tokens.css` | 색·글꼴·크기 변수, 층 순서 선언                                                      | —            |
| `src/ui/kit.css`    | **역할**: 표면, 머리띠, 버튼(기본·주요·선택·조용함), 행, 입력, 칩, 선택 묶음, 페이지 | `kit`        |
| `src/ui/system.css` | 부품 고유 모양(결과 도장, 계산기, 사슬, 다이얼)                                      | `components` |
| 화면별 CSS          | 배치(위치·크기·간격)만                                                               | `legacy`     |
| `src/render/ink.ts` | 지도 위 모든 그림의 붓: 잉크 외곽선, 평면 두 톤 음영, 낡은 질감, 리벳, 흙빛 팔레트   | —            |

층 순서는 `legacy < kit < components`라 선택자 구체성 싸움이 없다.

## 새 요소를 만들 때

- 누르는 것은 `<button>`이면 끝. 화면의 핵심 동작이면 `primary` 클래스, 켜짐/현재는 `aria-pressed`·`aria-current`.
- 새 패널은 `kit.css`의 Surface 목록에 선택자 한 줄, 패널 안 항목은 Row 목록에 한 줄.
- 지도 그림은 `ink.ts`의 `wobblyCircle/wobblyPoly → 평면 채움 → grime → ink` 순서로 그린다. 그라디언트는 빛(`glow`)에만 쓴다.

## 그림체 (산소미포함에서 빌린 것)

굵고 살짝 떨리는 어두운 갈색 외곽선 · 평평한 색면과 한 단계 어두운 그림자 면 · 크림/올리브/녹/황토/청록의 탁한 팔레트와 작고 선명한 불빛 · 깨끗한 벡터 대신 긁힘과 얼룩. UI는 같은 원칙을 슬레이트 패널, 어두운 남보라 머리띠, 눌리는 것 밑의 두꺼운 그림자 턱, 분홍 선택색으로 옮긴다.
