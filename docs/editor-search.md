# 풀이 탐색 계약

모든 실제 성공을 동등하게 다룹니다. 의도/기준/임의 성공 분류는 없습니다.
referencePlans는 다른 입력과 같은 제작 검증 기록이며 플레이 배포에서 제거합니다.

## 제작 흐름

빈 장면에서 천체·기체 출발·판정 그림 배치 → 제한 설정 → 풀이 탐색 →
같은 목록의 그룹 선택/예약 그림/설정/재생 → 조건 수정 → 재탐색입니다.
판정 도구의 역할은 [판정 오브젝트](mission-objects.md)를 참고하세요.
각 도구에 성공/실패 그림과 손잡이 안내가 있습니다. 원형 궤도는 높이 띠만으로 성공하지 않습니다.

파일·편집처럼 명령을 고르는 상단 메뉴는 상단 바 밖의 독립 팝업으로 엽니다.
다른 명령 메뉴를 열면 이전 메뉴가 닫히며 바깥 클릭·Esc·닫기 버튼·명령 실행으로 닫습니다.
팝업은 화면 경계 안에서 아래/위 방향을 고르고, 공간이 부족할 때만 팝업 자체를 스크롤합니다.
상단 바나 지도 크기를 바꾸지 않습니다. 속성 설명·배치 도구 목록처럼 맥락 안에서 내용을
읽거나 비교하는 항목은 기존 패널의 내부 펼치기로 유지합니다. 보관함·공유 서버와 판정
도구 안내처럼 별도 작업 흐름은 기존 독립 대화상자를 유지합니다.

전체 결과는 한 스크롤 영역에서 탐색합니다. 그룹마다 실제 경로 선택·재생,
성공 기록 보관·차단안이 있고 별도의 중복 대표 선택 탭·24개 페이지가 없습니다.
그룹 선택만 하면 경로를 강조하며 영상 재생은 재생 버튼을 누를 때 시작합니다.
모든 대표의 실제 경로는 연한 점선입니다. 예약 그림은 게임과 같은 SVG 아이콘을 사용하고,
누르면 시각·기체·출력 그림·방향 그림·분리 대상 설정을 보여 줍니다.
보관은 초안을 갱신하며 탐색 결과를 지우지 않습니다. 공유본에는 초안 저장을 별도로 실행합니다.

## 탐색 구조

[경우 분해·실행 배분·수학적 전제](search-algorithm.md)에 알고리즘과 비용을 기록했습니다.

- 실제 예약 문법의 DP/rank-unrank와 BigInt 격자 생성.
- 예약 길이·시간·정밀도 교차 확장. 낮은 층을 마칠 때까지 다른 층을 막지 않음.
- 유한 임무는 실제 전체 시간, 무제한 임무는 점차 확장한 유한 창에서 실행.
- 연료 로켓의 금지된 순간 Δv는 생성하지 않음. 분리체와 위성별 대상은 포함.
- 연속 값의 전역 분할/저불일치 표본/좌표 탐색. 실패 점만으로 구간 제거하지 않음.
- 실제 비행 상태를 작은 tick 묶음으로 보존/재개. 독립 경우는 최대 8개 교차 실행.
- 같은 입력 캐시 4096개, 최근 4개 층 DP, 그룹·매개변수 캐시.
- 한 배치 8192회 이하. 누적 8192회 상한 없이 더 조사로 이전 위치부터 이어감.
- Worker로 UI와 분리하고 최대 초당 10번 보고. 편집 변경은 revision을 갱신하고 작업 종료.
- 고차원 연속 제어는 실제 전이의 국소 이산 수반으로 공동 개선 방향을 계산합니다.
  실제 재비행으로만 성공을 채택하며 이 수치 미분으로 영역을 제외하지 않습니다.

## 작업자 수명과 실패 처리

탐색·설계 검사·대표 기록·차단안 Worker는 배포 번들에 포함합니다. 열린 탭에서 뒤늦게
이미 교체된 해시 파일을 요청하지 않습니다. HTML은 재검증하고 해시 JS/CSS만 불변 캐시합니다.
`SearchClient`는 작업 세대/revision을 확인해 이전 결과·오류를 무시합니다. 생성·전달·
역직렬화·계산 실패를 처리하고, 첫 연결 실패만 250ms 뒤1회 재시도합니다.
계산 중 실패는 찾은 경로를 지우거나 완전 조사로 표시하지 않고 중단 사유와 ‘다시 탐색’을
제공합니다. 이 버튼은 새 조사이며 실패한 열거 위치의 자동 복원이라는 의미는 아닙니다.

결과 전달은 ACK로 조절합니다. 화면이 이전 결과를 처리하기 전에는 전송1개와 최신 대기
결과1개만 유지하므로 느린 화면에 중간 보고가 무한 적체되지 않습니다. 중지·재개는 기존
작업이 살아 있을 때만 제공하고, 실패한 작업에 작동하지 않는 재개 버튼을 남기지 않습니다.
보조 작업자의 실패도 기존 경로/초안을 보존하고 해당 작업만 다시 시도할 수 있게 합니다.
브라우저 강제 종료·기기 메모리 고갈을 포함한 모든 실패의 부재를 증명한 것은 아닙니다.

## 제한 조사

특정 예약 구성을 선택하면 해당 변수의 고정/범위를 지정할 수 있습니다.
이는 전체 예약 문법의 탐색을 의도한 해 주변으로 바꾸는 기능이 아닌 별도 제한 조사입니다.
제작자가 직접 지정한 탐색 예약 상한은 계속 존중합니다.

## 유사도 그룹·차단안

실제 실행한 조작/대상, 시간에 무관한 공간 경로, 모든 분리체 최종 상태로 묶습니다.
작은 예약 시각 차이 때문에 비슷한 비행을 자동으로 나누지 않습니다.
정확한 계획 중복도 합칩니다. 실행되지 않은 suffix 제거는 별도 실제 비행에 성공한 경우만 합니다.

차단안은 지도 표식의 폭·반경·자세·물리 상태 범위·유지 구간을 수정한 뒤 다시 컴파일하고
실제 저장 표본을 검사합니다. 그림과 조건이 어긋난 수정안을 제공하지 않습니다.
다른 발견 해가 얼마나 남는지도 표시하고 특정 의도 해 보존을 강제하지 않습니다.
별도 설계 검사·공개 준비는 구조 오류·관측·조작 여유 검사이므로 남겨두되 중복 성공 집계는 제거했습니다.

현재 유사도 그룹은 연속 해의 위상학적 연결 성분 증명이 아니며 차단안은 유한 후보 검사입니다.
원본 조건을 몰래 완화하지 않습니다. 무제한/정확한 경계 해의 완전 판정과 검증된 구간 적분은
[추가 작업](remaining-work.md)에 남겨둡니다. 숫자로 보장율·성공 확률을 꾸며내지 않습니다.
