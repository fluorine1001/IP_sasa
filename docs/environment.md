# 개발 환경

현재 저장소의 TypeScript + Canvas + Vite 환경을 유지합니다. 전체 캔버스 세계와 게임 HUD를 사용합니다. 현 단계에서는 엔진 이전보다 비행 조작과 퍼즐 풀이를 반복 검증하는 데 집중합니다.

Node.js 24, 고정 npm lockfile, TypeScript, Vitest, Playwright Chromium, GitHub Actions를 사용합니다. 프로젝트 코드에는 특정 컴퓨터의 절대 경로가 없습니다. VS Code와 GitHub Desktop을 함께 사용할 수 있습니다.

개발 서버 `/?editor=1`에서 천체·대기·상호 중력·경로·게이트·정거장·표면 발사·로켓 단·공통 목표를 수정합니다. JSON은 `data/stages/`에 저장합니다. 배포 빌드에는 개발 제작 모듈과 API가 제공되지 않습니다.

현재는 데스크톱 브라우저 게임입니다. Steam 배포에는 네이티브 패키징·입력·해상도·세이브 경로·플랫폼 연동 검증이 더 필요합니다. 물리·조건·데이터가 화면과 분리되어 다른 렌더러로 옮겨도 목표 시스템을 유지할 수 있습니다.

그림과 소리는 코드로 제작한 임시 자산입니다. 추가 이미지 레퍼런스 없이 실행됩니다.
