# 발사 계획과 재생 계약

계획→실제 발사→관측→재생→수정의 루프입니다. 비행 중에는 예약 추가·변경을 금지합니다. 일시정지해도 같고 키보드·지도 입력도 이 잠금을 지킵니다. 환경은 같은 스테이지의 시도 사이에 고정합니다.

시간선 팔레트에서 조작을 끌어 배치하거나 클릭 후 시간선을 클릭합니다. 출력/방향/수정 추진은 선택 팝업으로 조절하고 분리/끄기는 슬라이더 없이 이동·삭제합니다. 같은 시각은 목록 순서대로 실행합니다. 다음 단은 자동 점화하지 않습니다. 분리체 엔진도 사전에 예약합니다.

첫 출력은 추진 가속과 연료 지속 시간을 알려줍니다. 이륙 가능 여부나 필요 출력·정답 경로는 계산해 안내하지 않습니다. 연료/재점화/예약 한도는 기체 제약으로 검증합니다. 미래 궤도는 표시하지 않습니다.

## 시간과 횟수

rules.timelineDuration은 예약 창, rules.maxTime은 관성 비행/관측까지 포함한 임무 시간입니다. 빈 예약 창은 maxTime을 사용합니다. commandLimits는 ignite/stop/turn/separate/push 각각 0~64회 또는 생략(무제한)입니다. 첫 발사는 제외하고 혼합 명령은 두 한도를 소비합니다. UI와 createRun은 같은 planConstraints를 사용합니다.

timelineUnlimited와 maxTimeUnlimited를 에디터에서 독립적으로 고릅니다. 숫자는 초기 표시 길이로 남고 JSON에 Infinity를 쓰지 않습니다. 무제한 계획은 ‘시간선 늘리기’와 시각 입력으로 확장하며 유한한 임무 종료 이후 예약은 거부합니다. 발사·재생 진행 바는 실제 시간에 맞춰 유한한 표시 창을 확장합니다.
목표별 endTimeUnlimited도 선택할 수 있습니다. 자동 execute 검사는 audit.timeLimit(빈칸이면 maxTime)에서 observed로 끝나므로 무제한 게임을 끝내거나 무한 루프에 빠지지 않습니다. 검사 범위 이후 성공 가능성은 미검증입니다.

## 회전

예약 방향은 발사대의 고정 기준축에서 −180°~180°인 목표 자세입니다. 순간 회전 대신 단별 turnRate로 최단 각도 방향으로 이동합니다. 기본 성능은 단이 가벼워질수록 빠르고 연료 감소에 따라 제한적으로 빨라집니다. 자세 변경은 몸체 중심을 유지하고 속도에 임의의 충격을 주지 않습니다. 엔진은 실제 현재 자세로 추진합니다. UI의 회전 시간은 기체 성능 안내이며 실제 궤도/목표 판정을 예측하지 않습니다.

## 기록 격리

Run.initialPlan은 발사 순간의 복사본입니다. Trial의 scheduledPlan은 당시 예약 전체, flightPlan은 명령 기록, appliedIds는 실행 여부, plan은 다음 시도에 복사할 실행 조작입니다. frames는 위치·속도·자세·연료·분리체·천체·충돌 상태를 저장합니다. 미실행 예약도 당시 바에 남습니다.

재생은 물리를 다시 실행하지 않고 약 20Hz 상태와 명령 순간 프레임을 보간합니다. 각도는 최단 호로 보간하고 분리 때 끝 위치를 보정합니다. 이산 상태는 일찍 바꾸지 않습니다. 기록 끝 이후로 이동하지 않으며 원본/현재 계획을 수정하지 않습니다.

재생 로켓은 불투명도 0.72, 약한 잡음·스캔선으로 구별합니다. 동작 줄이기는 잡음 갱신을 멈춥니다. 기본 카메라는 로켓 추적이며 WASD/휠/가운데 드래그로 풀고 C로 복귀합니다.

## 몸체·충돌·파일

world/hull.ts 치수를 그림/물리/재생이 공유합니다. 단은 0.12u, 탑재체는 0.10u이며 플레이어가 길이를 바꾸지 않습니다. 분리하면 위 로켓 바닥은 한 단 앞쪽으로 이동하며 코끝이 이어지고 운동량을 보존하는 작은 스프링이 두 몸체를 분리합니다.

연속 이동 캡슐/원 교차로 코끝·옆면·고속 접촉을 검사합니다. 전체 몸체를 표면 밖으로 배치하고 한 번의 감쇠 반동 후 실패합니다. 렌더 확대가 충돌 치수를 바꾸지 않습니다. 로켓 아트와 PNG 출력은 render/rocket-sprite.ts, assets/rockets/manifest를 기준으로 합니다.

flight/screen.ts는 세션, timeline.ts는 바/목록, planner.ts는 직접 조작, propulsion.ts는 기체 안내, world/program.ts는 계획 규칙, world/replay.ts는 녹화/재생입니다. tutorial/settings는 자신의 폴더에서 독립 개발합니다.
