# 발사 계획과 재생 계약

계획→실제 발사→관측→재생→수정의 루프입니다. 비행 중에는 예약 추가·변경을 금지합니다. 일시정지해도 같고 키보드·지도 입력도 이 잠금을 지킵니다. 환경은 같은 스테이지의 시도 사이에 고정합니다.

상세 조작·실험 학습은 단일 튜토리얼 스테이지가 담당합니다. 본편에는 훈련 체크나 관련 UI 강조를 만들지 않습니다. 목표 조건 확인과 기록된 수치 비교는 모든 플레이 화면에서 사용할 수 있는 기본 정보입니다.

본편에서는 learning.briefing·상황 단서의 조언 문구·학습 범위의 조언 문구를 표시하지 않고 상황 단서의 학습용 자동 정지도 적용하지 않습니다. 성공 조건은 명령 절차나 수식 대신 달성 상태·허용 범위·유지 시간·필수 사건 기록으로 보여줍니다. 상세 실험 안내와 한 변수 비교의 조언 문구는 튜토리얼에서만 사용합니다. 제작 시험의 관측 기능은 유지합니다.

관제석의 기록 버튼이 다시보기의 유일한 진입점입니다. 기록의 경로 그림을 선택하면 현재 지도에 실제 기록된 점선만 표시하며 영상은 재생하지 않습니다. 카드의 재생 버튼은 녹화 영상을 실행하며 모니터 노이즈·스캔선과 ‘비행 화면으로’ 복귀 버튼을 표시합니다. 결과 화면에는 재생·계획 복귀·나가기 버튼을 중복 배치하지 않습니다. 종료는 짧은 상태 카드로 표시하고 관제석의 발사 버튼이 ‘계획 편집’으로 전환됩니다. 발사 기회를 모두 소진하면 같은 버튼으로 새 도전을 시작하며 이전 기록은 유지합니다. 자동 나가기 질문은 하지 않습니다.

팔레트 버튼 활성 상태는 planner.sync만 소유합니다. 발사 전/후와 예약 종류별 한도를 함께 적용하고 상태가 달라질 때만 disabled를 수정합니다. screen.updateHud는 engine/separate의 활성 상태를 덮어쓰지 않습니다. 한도 0 또는 한도 도달 시 반복 갱신으로 활성/비활성이 왕복하던 깜박임을 막습니다.

world/plan-diff는 생성 ID를 제외한 초기 출력·명령 시각·출력·방향·대상을 비교합니다. 하나의 수치만 바꾸어 실제 발사한 경우에만 튜토리얼의 한 변수 실험으로 인정합니다. 비교표는 관측 수치·측정 시각·비행 길이와 녹화 프레임의 위치·속력·연료를 사용하며 기록 종료 이후 값을 추정하지 않습니다.

시간 바를 클릭·드래그하거나 예약 시각 숫자를 입력해 시각을 고르고, 팔레트의 조작 버튼을 누르면 그 시각에 추가합니다. 선택 시각은 Timeline 내부 UI 상태이며 Run이나 기존 명령을 수정하지 않습니다. 방향키는 0.01초, Home/End는 표시 창 양 끝입니다. 숫자 입력은 표시 창을 확장할 수 있지만 유한한 예약 종료 시각을 넘기지 않습니다.

팔레트에서 조작을 끌어 배치하는 방식도 유지합니다. 기존 예약 그림의 드래그는 해당 명령의 시각만 변경합니다. 출력/방향/수정 추진은 선택 팝업으로 조절하고 분리/끄기는 슬라이더 없이 이동·삭제합니다. 같은 시각은 목록 순서대로 실행합니다. 다음 단은 자동 점화하지 않습니다. 분리체 엔진도 사전에 예약합니다.

동일한 range 바를 계획 시각 선택과 실제 기록 탐색에 사용하되 콜백에서 phase를 구분합니다. 발사 전에는 시각 선택만, 다시보기에는 기록 seek만 수행하고, 비행 중에는 disabled이며 일시정지 중에도 편집하지 않습니다. 시간 바의 선택 위치와 실제 비행 시계는 별개입니다.

첫 출력은 추진 가속과 연료 지속 시간을 알려줍니다. 이륙 가능 여부나 필요 출력·정답 경로는 계산해 안내하지 않습니다. 연료/재점화/예약 한도는 기체 제약으로 검증합니다. 미래 궤도는 표시하지 않습니다.

## 시간과 횟수

rules.timelineDuration은 예약 창, rules.maxTime은 관성 비행/관측까지 포함한 임무 시간입니다. 빈 예약 창은 maxTime을 사용합니다. commandLimits는 ignite/stop/turn/separate/push 각각 0~64회 또는 생략(무제한)입니다. 첫 발사는 제외하고 혼합 명령은 두 한도를 소비합니다. UI와 createRun은 같은 planConstraints를 사용합니다.

timelineUnlimited와 maxTimeUnlimited를 에디터에서 독립적으로 고릅니다. 숫자는 초기 표시 길이로 남고 JSON에 Infinity를 쓰지 않습니다. 무제한 계획은 ‘시간선 늘리기’와 시각 입력으로 확장하며 유한한 임무 종료 이후 예약은 거부합니다. 발사·재생 진행 바는 실제 시간에 맞춰 유한한 표시 창을 확장합니다.
목표별 endTimeUnlimited도 선택할 수 있습니다. 자동 execute 검사는 audit.timeLimit(빈칸이면 maxTime)에서 observed로 끝나므로 무제한 게임을 끝내거나 무한 루프에 빠지지 않습니다. 검사 범위 이후 성공 가능성은 미검증입니다.

## 회전

예약 방향은 발사대의 고정 기준축에서 −180°~180°인 목표 자세입니다. 순간 회전 대신 단별 turnRate로 최단 각도 방향으로 이동합니다. 기본 성능은 단이 가벼워질수록 빠르고 연료 감소에 따라 제한적으로 빨라집니다. 자세 변경은 몸체 중심을 유지하고 속도에 임의의 충격을 주지 않습니다. 엔진은 실제 현재 자세로 추진합니다. UI의 회전 시간은 기체 성능 안내이며 실제 궤도/목표 판정을 예측하지 않습니다.

## 기록 격리

Run.initialPlan은 발사 순간의 복사본입니다. Trial의 scheduledPlan은 당시 예약 전체, flightPlan은 명령 기록, appliedIds는 실행 여부, plan은 다음 시도에 복사할 실행 조작입니다. frames는 위치·속도·자세·연료·분리체·천체·충돌 상태를 저장합니다. 미실행 예약도 당시 바에 남습니다.

재생은 물리를 다시 실행하지 않고 약 20Hz 상태와 명령 순간 프레임을 보간합니다. 각도는 최단 호로 보간하고 분리 때 끝 위치를 보정합니다. 이산 상태는 일찍 바꾸지 않습니다. 기록 끝 이후로 이동하지 않으며 원본/현재 계획을 수정하지 않습니다.

재생 로켓은 불투명도 0.72, 약한 잡음·스캔선으로 구별합니다. 동작 줄이기는 잡음 갱신을 멈춥니다. 기본 카메라는 로켓 추적이며 WASD/휠/가운데 드래그로 풀고 C로 복귀합니다.

## 몸체·충돌·파일

world/hull.ts 치수를 그림/물리/재생이 공유합니다. 단은 0.12u, 탑재체는 0.10u이며 플레이어가 길이를 바꾸지 않습니다. 분리하면 위 로켓 바닥은 한 단 앞쪽으로 이동하며 코끝이 이어지고 운동량을 보존하는 작은 스프링이 두 몸체를 분리합니다.

연속 이동 캡슐/원 교차로 코끝·옆면·고속 접촉을 검사합니다. 전체 몸체를 표면 밖으로 배치하고 한 번의 감쇠 반동 후 실패합니다. 렌더 확대가 충돌 치수를 바꾸지 않습니다. 로켓 아트와 PNG 출력은 render/rocket-sprite.ts, assets/rockets/manifest를 기준으로 합니다.

flight/screen.ts는 세션, timeline.ts는 바/목록, planner.ts는 직접 조작, propulsion.ts는 기체 안내, world/program.ts는 계획 규칙, world/replay.ts는 녹화/재생입니다. tutorial/settings는 자신의 폴더에서 독립 개발합니다.

## 시각적 조작과 플레이어 주도 실습

단일 튜토리얼은 7개 활동 묶음입니다. 행동 기록과 안내 페이지를 분리해 완료만으로 자동 전환하지 않고 다음·이전·목록으로 이동합니다. 검은 강조는 빠르게 등장하고 원이 화면 모서리 밖까지 커진 뒤 사라집니다. 설명 패널은 남으며, 가까운 위치로 빠르게 이동한 후 강조 확장과 함께 관제석 위 우측 하단으로 이동합니다. 버튼·입력·스크롤 영역을 제외한 본문을 드래그해 화면 어디든 놓을 수 있고 최소화·복원합니다. 상세 설명은 고정 높이의 내부 스크롤, 패널 전체는 별도 스크롤이며 버튼 위에서도 휠 입력을 처리합니다. 강조 대상은 잘린 경우 먼저 스크롤해 드러냅니다.

예약 선택 팝업은 표식 위에 표시합니다. 분리·끄기는 삭제만 표시하고 출력은 불꽃·추력 화살표·연료 흐름의 정적 기체 그림을 포함합니다. 방향판을 눌러 방향을 고르고 숫자 편집은 정밀 입력의 대체 수단으로 남습니다. 대상 기체는 본체(분리 후 남은 로켓)와 분리체(떨어져 나온 단)로 구분하고 구성 그림을 표시합니다.

실제 분사만 화면상 최소 크기의 외부 불꽃으로 표시하고 출력에 따라 크기가 달라집니다. hull 그림·충돌 크기는 확대하지 않습니다. 궤적은 기체 중심의 이동을 기록해 무추력 회전에서 노즐이 움직인 호를 궤적으로 오인하지 않게 합니다. 카메라는 같은 중심을 지수 보간으로 따라가며 분리·기체 전환 때 즉시 튀지 않습니다. 물리의 기체 기준점은 기존 hull 바닥 계약을 유지합니다.
