## 이른 접촉의 범위

화면 축척 상한은 350px/u, 로켓 반지름은 0.035u이므로 요청 기준은 0.00175u (0.6125px) 이하입니다. 깊이 12의 각 남은 시간구간은 최초 슬라이스의 최대 1/4096이며, 0.01초 물리 슬라이스에서 최대 약 0.000002442초입니다. 하지만 상대 이동량과 기체 회전량으로 정해지는 거리 상수에 전역 상한이 없고, 가까이 다가가기만 하고 접촉하지 않는 경우에는 실제 접촉 시각 자체가 없습니다. 따라서 모든 입력에서 거리 기준을 만족했다고 증명하지 못했습니다. 현재 알고리즘은 시간 경과 하한 1e-12도 사용하므로 수치 경계의 충돌 누락 가능성 역시 별도 검증이 필요합니다.
