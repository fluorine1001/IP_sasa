# 2D 임무 판정 오브젝트와 연결 계약

이 제작소의 실행 엔진은 임무 이름으로 분기하지 않는다. 지도에서 만든 관측 주석을
Condition/Expression으로 컴파일하고, 실제 비행의 동일한 상태·사건·관측 구간을 판정한다.
“가깝게”, “안정적으로” 등의 문구가 숨은 허용값을 선택하지 않는다.
판정 오브젝트는 벽·통과 게이트·추진을 바꾸는 물리 물체가 아니다.

## 제작 흐름

1. 천체·실제 위성·착륙 지점·소행성과 출발 위치를 배치한다. 천체는 고정, 지정 원운동,
   상호 중력 중에서 정하고, 초기 궤도 도구로 원·타원·포물선·쌍곡선 속도를 설정할 수 있다.
2. 발사 횟수, 종류별 예약 횟수, 계획·임무 시간 제한을 설정한다.
3. 판정 도구를 고르고 기준 연결·경계 미리보기를 확인한 뒤 드래그로 그린다. 노란 손잡이로 설치 후에도 조절한다.
4. 판정 대상 기체와 따라갈 기준 대상을 선택한다. 탑재체는 실제 분리된 뒤부터 판정한다.
5. 필요한 표식만 연결하고 동시 충족·하나 이상·순서를 선택한다.
6. 유효해 탐색에서 발견한 모든 성공 집합을 확인하고 대표 실제 기록을 재생한다.
   임의/기준/의도 성공을 분류하거나 어느 기록을 특별히 보존하지 않는다.

새 스테이지는 천체·기체·판정이 모두 비어 있습니다. 출발 위치는 천체 표면에 제한하지 않습니다. 천체가 없는 공간/속도/상태 판정은 고정 좌표 기준 `origin`을 사용할 수 있습니다. 이는 세계 원점 주석이지 물리 물체가 아닙니다. 각 도구에는 그림·성공 사례·실패 사례·조절 손잡이 안내가 있습니다.

## 배치 중에 작동하는 제작 가이드

시작 예시와 별개로 모든 판정 설치·손잡이 조작에 동일한 제작 계약을 적용합니다.
이 가이드는 현재 장면의 도형과 판정 구조를 계산하며 무료 비행이나 미래 경로를 시뮬레이션하지 않습니다.

- 배치 전 경계 미리보기와 기준 대상의 테두리·연결선이 나타납니다. 기준 대상을 선택창에서 고정할 수 있습니다. 드래그 시작 시 대상을 고정해 다른 천체 근처를 지나도 바뀌지 않습니다.
- 영역·속도·상태는 실제로 가리킨 물체 또는 고정 좌표에 붙습니다. 멀리 있는 천체를 몰래 선택하지 않습니다. 궤도·접촉·전후 관측은 각 판정에 필요한 실제 천체/표면만 기준으로 고를 수 있습니다.
- 원은 중심에서 테두리까지, 궤도·최근접 띠는 기준 중심에서 반경까지, 속도는 시작점에서 화살표 끝까지 드래그합니다. 속도 도구의 단순 클릭은 상대속도 0입니다. 기체나 대상의 실제 속도를 바꾸는 기능이 아닙니다.
- 궤도 손잡이는 `a(1−e)−허용 폭 > 천체 반지름`을 만족하는 범위에 머뭅니다. 천체 내부를 가로지르는 타원이나 순서가 뒤집힌 접근/최근접/이탈 원이 생기지 않도록 도형만 보정합니다. 엔진 꺼짐·기체·시간 구간 조건을 자동으로 완화하지 않습니다. 궤도에는 접선 방향 표시와 실제 한 바퀴 요구가 함께 나타납니다.
- 접촉 표식의 위치는 실제 천체 표면을 따라 움직이며 자세 부채꼴과 착륙 기체 그림을 같이 표시합니다. 상태 관측은 지도에 색칠한 구간과 두 끝 손잡이를 제공하며 확대·카메라 위치가 실제 허용값을 바꾸지 않습니다.
- 작은 원의 손잡이는 잡기 쉬운 화면 간격까지 뽑아 연결선으로 경계를 가리킵니다. 실제 원 자체를 크게 만드는 것이 아니며 화면 오프셋과 잡은 지점을 역변환해 값이 뛰지 않습니다. 선택한 접촉 표식은 겹친 로켓/천체보다 먼저 선택합니다.
- **표면·도형 경계에 맞춤**을 끄면 유효한 도형을 자유롭게 조절할 수 있습니다. 구조적으로 잘못된 후보는 빨간 표시와 원인으로 알려 주고 저장된 마지막 유효 도형은 유지합니다. 자유도는 고급 조건 블록에서도 유지하며 수동 조건을 덮어쓰지 않습니다.
- 각 선택 표식의 검사 범위를 작은 체크판으로 구분합니다. 영역은 위치만, 속도는 상대속도만 검사합니다. **상대속도/위치도 같은 순간에 검사**를 직접 누른 경우에만 같은 기체·기준·구간의 표식을 추가하고 AND 연결합니다. 기존 AND/OR/순서 부모는 이 묶음을 참조하도록 바뀌며 다른 시각의 과거 완료를 합치지 않습니다. 제작자가 요구하지 않은 ‘랑데부’ 조건을 자동으로 추측하지 않습니다.

보정은 도형/연결 오류를 줄이는 장치이지 이륙·도달·목표 달성 가능성의 인증이 아닙니다.
겹친 실제 물체, 부족한 추력·연료, 서로 모순되는 사용자 고급 조건 등은 실제 탐색·시험으로 별도 확인해야 합니다.
390px에서는 배치 안내를 지도 위의 별도 공간에 두어 클릭·드래그할 지도를 가리지 않습니다.

로켓 출발 위치는 공유 hull의 실제 몸체·천체 경계를 사용하며 넓은 화면 픽셀 자석을 쓰지 않습니다.
마우스 또는 로켓 바닥이 천체 내부로 들어가거나 동체가 경계에 접촉하면 표면 바깥으로 정렬합니다.
내부의 마우스 방향을 따라 표면 위를 이동하고, 정확히 중심을 가리키면 직전 방향을 유지합니다.
바깥으로 끌어 떼면 연결을 해제하고 자유 공간 위치·초기 속도를 사용합니다.
행성/달을 로켓 쪽으로 움직여도 같은 접촉을 적용하며 최초 접촉부터 이동을 따라갑니다.
빠른 천체 이동은 두 입력 사이의 연속 원/캡슐 교차를 검사해 접촉을 건너뛰지 않습니다.
붙은 로켓의 실제 초기 위치·속도는 매 입력마다 갱신하고 드래그 종료를 기다리지 않습니다.
지정 운동의 부모 이동도 실제 초기 천체 위치로 처리하며 undo/드래그 취소는 천체·로켓·연결을 함께 복원합니다.
태양/블랙홀 내부도 피하지만 착륙 가능한 발사대로 취급하지 않으며, 행성/달 표면 연결에만 발사대를 표시합니다.
여러 천체가 겹친 경우에도 전체 동체를 다시 검사합니다. 제한된 국소 보정으로 해소되지 않으면
모든 천체의 지지 반평면 바깥 자유 공간으로 옮기고 표면 연결을 해제합니다. 이때 거짓 발사대를 만들지 않습니다.

구버전 문서에 남은 수정되지 않은 임시 예시는 첫 실제 판정 배치 때 교체하며, 수정하거나 명시적으로 참조한 예시는 보존합니다. 새 문서에 예시를 자동 설치하지 않습니다.

## 표식 → 실제 판정

| 표식           | 제작자가 조절하는 그림                              | 실제 판정                                                               |
| -------------- | --------------------------------------------------- | ----------------------------------------------------------------------- |
| 공간 판정 원   | 중심·반경, 내부/외부                                | 선택 기준의 이동에 따라가는 상대 위치가 원 내부 또는 외부               |
| 궤도 판정 안내 | 긴·짧은 반경, 허용 폭, 최근접 방향                  | 거리, 실제 긴 반경, 이심률 및 타원 최근접 방향 범위와 엔진 꺼짐         |
| 속도·방향 표적 | 속도 화살표와 끝의 허용 원                          | 상대 속도 벡터와 화살표 벡터의 차이가 허용 반경 이내                    |
| 접촉 판정 지점 | 위치 원, 착륙 자세 부채꼴                           | 해당 천체에 실제 안전 접촉, 지점 내부, 기체의 접촉 속력 한계, 허용 자세 |
| 상태 관측 표식 | 물리 속성, 색칠한 허용 구간                         | 해당 속성이 표시 범위 내부/하한 이상/상한 이하                          |
| 전후 변화 관측 | 진입·이탈 원, 최근접 띠, 전후 관측 기준과 허용 구간 | 접근 순간 값을 기록하고 최근접 띠를 지나 이탈할 때 차이 검사            |

순간·연속 시간·실제 한 바퀴 중에서 관측 구간을 지정한다. 궤도는 기본적으로
엔진을 끄고 실제 한 바퀴 내내 조건이 성립해야 한다. 한 바퀴 판정은 현재 구간의
순회량과 최소 조건 여유를 검사하므로 띠를 직선으로 잠깐 지나는 비행은 인정하지 않는다.
“전후 변화”는 진입·최근접·이탈 사건을 순서대로 검사한다. 추가 추진 금지 옵션은
선택 기체의 연료 소비와 수정 추진 기록의 변화도 검사한다.

## 특정 임무 이름 없이 구성하는 예

- 랑데부: 대상 위성에 붙인 공간 원 + 상대속도 화살표(중심 0)의 허용 원을 동시 연결한다.
  서로 다른 시각의 최소 거리/최소 상대속도를 모아 성공시키지 않는다.
- 착륙·부스터 회수: 회수할 분리체를 지정한 접촉 표식. 목표 지점을 스치거나 반대쪽 표면에
  내려앉는 것으로 완료되지 않는다.
- 탈출: 천체 중심의 외부 공간 원 + 에너지 0 이상 + 바깥 방향 속도 구간을 동시 연결한다.
  필요 없는 에너지 상한이나 원운동 유지 조건을 붙이지 않는다.
- 스윙바이: 통과 천체에 전후 변화 관측을 붙이고 실제 최근접 띠, 진입·이탈 거리,
  에너지를 관측할 다른 천체, 요구 변화 구간을 지정한다. 추가 추진 금지 옵션으로
  엔진에서 얻은 성과를 중력 도움으로 대체하지 못하게 한다.
- 위성 배치: 로켓에 탑재체를 추가하고 분리 예약을 허용한다. 궤도 표식의 대상으로
  여러 위성을 선택하면 분리된 각각의 실제 궤도를 검사한다. 서로 다른 궤도에는
  표식을 따로 두고 다시 연결한다. 공통 상태뿐 아니라 각 위성의 조건을 따로 정할 수 있다.
- 다른 구성: 공간·속도·상태·접촉·전후 관측 표식의 논리/순서 연결을 다시 연결할 수 있다.
  고급 조건 블록에는 계산, 순간 기록, 구간 통계, 집합 모두/일부/지정 개수 조건이 남아 있다.

이 예들은 시작 방법일 뿐, 엔진의 미션 종류 목록이 아니다. 제작 예시 폼 역시 선택적 도구다.

## 판정 그래프의 의미

새 Condition `reference`는 다른 표식의 **현재 조건**을 해당 연결의 독립된 기억으로
다시 관측한다. 완료된 표식의 과거 complete 값을 가져와 동시 성공을 만들지 않는다.
참조된 표식은 편집 가능한 구성 요소이며, 참조되지 않은 최상위 목표만 임무 완료를 결정한다.
`sequence`는 다음 조건의 기억과 구간 관측을 앞 조건 이후에 시작한다.
`once`로 과거 달성을 의도적으로 고정할 수 있고, `hold`로 연속 유지를 요구한다.

집합 조건 `quantify`는 각 기체·대상 조합에 독립된 시간/기록 기억을 부여한다.
`$actor`, `$target`은 집합 내부에서만 유효하다. 존재하지 않거나 파괴된 기체의 관측은
알 수 없는 값이며 NOT을 통해 유효한 물리 상태로 바꾸지 않는다.
참조·선행 관계 순환과 지나치게 큰 교차 집합은 저장/공개 검사에서 거부한다.
전체 장면의 확장 조건 비용 상한은 32768, 원본 조건 깊이 12/512노드와 수식 깊이 16이다.
이는 미션 종류 제한이 아니라 실시간 계산량의 안전 상한이다.

수동으로 컴파일 결과를 편집하면 해당 자동 메타데이터는 관리 해제된다. 자동 새로 계산이
사용자 정의 조건을 덮어쓰지 않는다. 관리 중인 표식의 그림과 컴파일 조건이 불일치하면
검사 오류로 드러나고 공개할 수 없다. 복사·붙이기는 참조 ID와 관리 키를 함께 갱신한다.

## 물리 및 탐색의 정직한 범위

현재 모델은 평면 뉴턴 중력, 대기 항력·가열·동압, 유한 추력·연료·회전,
다단 로켓 및 독립 탑재체다. 위성/파편은 천체의 중력을 받는 질량 없는 시험입자로
움직이며 천체를 역으로 끌어당기지 않는다. 탑재 위성은 현재 수동 비행하며 자체 엔진은 없다.
행성·달 사이의 상호 중력은 실제로 적분한다. 고정/지정 운동은 제작자가 선택한 경계 조건이다.
로켓과 단의 충돌은 공유 hull 형상을 사용한다. 실제 정거장/위성/파편의 충돌 크기를 따로
가지며, 구형 관측용 정거장은 실제 크기를 정하기 전 공개할 수 없다.
구형 게이트·즉시 실패 영역·강제 경로는 호환 로딩은 하되 새 공개 임무에서 허용하지 않는다.

임무 조합에 이름 목록의 제한은 없지만 아직 모델링되지 않은 물리 현상까지 판정할 수 있다는
뜻은 아니다. 도킹 결합, 위성 자체 추진, 상대론·3D 궤도면 등은 현재 물리 모델에 없다.
필요한 경우 물리 상태/관측 속성을 먼저 구현하고 같은 Condition 언어로 연결해야 한다.
물리 판정은 0.01초의 결정적 수치 적분과 swept 충돌 검사를 사용한다. 임의의 실수 시간에서
수학적으로 정확한 연속 판정을 주장하지 않는다.

탐색은 모든 합법 예약 구성을 공정하게 열거하고, 연속 변수 영역을 적응적으로 조사한다.
성공 집합은 실제 중간 성공 표본으로 연결되며 가까운 실패/미검사 구간을 성공으로 보간하지 않는다.
유한 예산으로 무한한 연속 해 전체·유일해·모든 차단 방법의 완전성은 증명할 수 없다.
각 그룹의 실제 대표 기록과 조사 범위/미검사 범위를 보고 수정을 반복해야 한다.
