# 게임성 검토와 로컬 개편 · 2026-10-28

이 문서는 현재 코드에서 관찰한 사용성·학습 문제를 연구에 비추어 해석한 설계 기록입니다. 초심자 사용자 실험을 완료한 결과 보고서가 아닙니다. 제작소 자동 해 탐색은 이번 사용자 지시에 따라 제품 흐름에서 폐지했습니다. 연구 알고리즘의 성공·완성을 뜻하지 않습니다.

## 실제로 바꾼 흐름

### 플레이

챕터 지도 → 임무 선택 → 예약 → 실제 비행 → 실제 기록 비교 → 수정입니다. 기존 UUID와 완료 기록을 유지합니다. 튜토리얼은 별도이고 일반 임무에는 풀이 순서·정답 예약·미래 경로·성공 확률을 넣지 않습니다. 챕터는 정리와 진행 피드백이며 강제 잠금이 아닙니다.

모든 재시도에서 물리 환경은 고정됩니다. 횟수 소진으로 기록을 버리거나 처음부터 시작하지 않습니다. 현재 배속 보존, 예약 그림, 실제 기록 점선, 단일 기록 목록 등의 기존 조작은 유지합니다.

### 제작

장면·기체·판정 도구 선택 → 지도에 배치/선택 → 오른쪽 주요 속성 조절 → **시험 비행(F5)** → **← 제작소** → 수정입니다. 파일·편집 명령은 독립 메뉴이며 도구의 물리/그림 의미는 해당 맥락과 안내에서 확인합니다. 고급 조건 언어·위성/부스터·임무 연결·운동 설정은 삭제하지 않습니다.

로켓 선택 시 각 단의 **연료 총량과 최대 추력**을 먼저 보여주고 나머지 질량·엔진·회수 수치는 상세에 둡니다. 천체 질량은 숫자와 중력 세기 슬라이더 모두로 편집합니다. 선택/드래그/겹친 대상 순환은 기존 공통 동작입니다.

편집만으로 실제 비행이나 해 검색을 실행하지 않습니다. 구조/배치 점검은 비행 없는 정적 검사입니다. 직접 비행의 목표 완료 시 실제 예약을 제작 검증 기록으로 보관합니다. 공개 요청은 서버가 그 기록을 현재 장면에서 다시 실행해 최소 한 개의 실제 성공을 확인합니다. 기록이 없거나 장면 변경으로 실패하면 공개를 거절합니다. 임의 발사·자동 해 생성·임의 성공률·단순 풀이 차단 기준은 없습니다.

수동 기록은 기존 IndexedDB에 저장합니다. 환경·목표·기체/조작 제한이 바뀌면 분리하고 이름·챕터·카메라만 바뀌면 유지합니다. 서버 스테이지·공개 스냅샷·플레이 진행도는 기존 저장 경계를 유지합니다.

## 착륙 기준

접촉 순간의 속도에서 **이동하고 자전하는 표면 속도**를 빼고, 법선 성분 n과 접선 성분 t를 계산합니다. 기체 또는 목표의 접촉 기준을 L이라고 할 때 표준 허용 영역은 `(n / 1.5L)² + (t / 3L)² ≤ 1`입니다. 정밀 모드는 전체 상대 접촉 속력 `≤ L`을 요구합니다. 표준 목표 자세에는 15°의 여유를 추가하고 최대 90°를 넘지 않습니다.

약한 옆미끄러짐이 강한 지면 충돌과 같은 기준으로 실패하던 문제를 줄입니다. 빠른 정면 충돌, 다른 지점의 접촉, 잘못된 자세, 유지 시간 부족은 계속 실패합니다. 실제 착륙 지점/자세 목표를 없애지 않습니다. 공통 로더는 이전 `touchdownSpeed` 조건을 한 번만 이관하고, 제공된 정밀 모드는 보존합니다.

관측 계기는 현재 주 로켓 또는 그 실제 다시보기의 충격 성분과 기체 한계만 보여줍니다. 앞으로의 제동 시점이나 착륙 성공 예측이 아닙니다. 목표가 기체보다 엄격하면 계기 안에 들어도 목표를 만족하지 않을 수 있습니다. 실제 저장 속력은 느슨한 값으로 위장하지 않습니다. 접촉 후 즉시 표면에 정착하는 모델은 게임 근사이며 실제 다리·탄성·지면 마찰 해석은 아닙니다.

## 챕터와 중력 데이터

`Stage.chapter`은 `{ id, title, order }`입니다. 같은 챕터 ID를 가진 스테이지를 묶습니다. 구버전은 임무 순서 1~3 / 4~8 / 나머지로 자동 분류합니다. 물리 판정은 챕터나 미션 이름으로 분기하지 않습니다. 저장한 사용자 챕터를 다른 문서에서도 선택할 수 있고 공개·빌드 스냅샷에도 메타데이터가 전달됩니다.

G 기본값은 사용자 요청의 반올림 값 `6.674e-11`입니다. 내부 중력의 원천은 계속 GM입니다. 질량 입력은 `M=mu/G`이며 G 변경 시 M을 보존해 mu를 다시 계산합니다. 기존 mu를 G로 다시 곱해 궤도를 바꾸지 않습니다. kg 해석은 게임 길이·시간 단위를 m·s로 본 값이며 현실 천체 데이터셋으로의 자동 변환이 아닙니다.

## 검증과 한계

단위 회귀는 접촉 성분·자전 표면·빠른 충돌 거절·정밀 모드·반복 이관, G/질량 변환, 챕터 분류와 UUID 진행도, 제공 기록만 공개 재검증하는 계약을 검사합니다. 브라우저 회귀는 실제 시험 비행/저장/왕복, 여섯 임무의 실제 계획 UI 실행, 챕터 선택, 초안과 공개 목록의 분리, 모바일 메뉴와 화면 범위를 검사합니다. 과거 자동 검색 화면 회귀는 `tests/archived-search/`에 보존하며 현재 제품 회귀로 실행하지 않습니다.

실제 초심자의 재미와 이해도는 아직 측정하지 않았습니다. 최소 다음 관찰이 필요합니다: 설명 없이 첫 예약 편집을 찾는지, 충돌 원인을 자기 말로 구분하는지, 기록을 보고 한 변수만 바꾸는지, 원하는 물체/판정을 편집기에서 찾는지. 외부 분석 전송이나 개인 식별 기록은 추가하지 않았습니다. 챕터 분류가 스테이지 자체의 다양성·난이도 품질을 보증하지도 않습니다.

## 미술 구현

탐험 게임의 두꺼운 잉크 윤곽, 산업 계기의 에나멜, 종이색 입력 표면을 참고한 독자적 CSS/SVG입니다. 타 게임 이미지·아이콘·폰트를 복사하지 않습니다. 고정된 미세 질감과 명암을 사용하고 외부 폰트 다운로드·프레임마다 노이즈 계산은 추가하지 않습니다. 버튼/입력의 대비·포커스·작은 화면의 메뉴를 함께 검사합니다.
