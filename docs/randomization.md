# 환경 고정과 실험 기록

이전의 발사별 랜덤 재시도 설계는 폐기했습니다. 현재 일반 플레이와 F5 시험은 원본 스테이지의 같은 초기 위치·속도·중력·대기·공전 위상을 매번 사용합니다. 모든 시도에서 실제 경로·관측·조작을 비교할 수 있습니다. 관측 장비·연료·분리체의 물리 상태는 각 발사에서 초기화되며, 기록이 남는 것이 다음 로켓에 힘이나 장비를 주지는 않습니다.

발사 횟수는 한 도전의 실험 예산입니다. 다 쓰고 새 도전을 시작하면 예산을 다시 받되 같은 환경과 기록은 유지합니다. 다른 임무로 나가거나 새로 입장하면 실험 기록은 초기화합니다. 완료·해금 정보만 스테이지 사이에 공유합니다.

`variation.ts`, `dimensions.ts`, `editor/randomization.ts`와 `generate:variations`는 기존 변형 제작 연구용으로 남았습니다. 저장된 변형은 일반 플레이에서 선택하지 않으며 제작 Worker도 자동 생성하지 않습니다. 출판 필수 조건이 아닙니다. 기존 변형의 성공 경로 검사는 회귀 검사로 유지하지만 이전 관측의 무효화나 명령 재사용 차단을 현재 게임 목표로 삼지 않습니다.

새 퍼즐의 관측·단서 제작은 [퍼즐 진행과 제작](puzzle-loop.md)을 참고하세요.
