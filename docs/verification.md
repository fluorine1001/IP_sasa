# 검증 기록

2026-10-11, IP_sasa의 codex/game-workshop에서 확인했습니다.

- TypeScript strict, 담당 모듈 경계·스테이지 UUID 검사, Vite 배포 빌드, 포맷 검사 통과.
- Vitest 91개 통과. 물리·목표 조합·에디터·고정 환경·계획 규칙·재생·단 분리·충돌과 함께, 제한된 회전 속도/중심 유지, 예약 종류별 횟수, 계획/임무 시간 분리, 무제한 시간 JSON 왕복, 늦은 목표 판정, 자동 검사 유한 종료를 검증합니다.
- Playwright Chromium 전체 30개 통과. 탐사 시작→스테이지 선택, 독립 도움말/설정, 표면 발사/카메라, 직접 시간선 배치/이동, −180°~180° 슬라이더, 분리/끄기의 값 편집창 생략, 예약 한도/삭제 회복, 비행 중 잠금, 당시 계획 재생, 실제 스테이지 독립성을 검사합니다.
- 무제한 옵션은 에디터에서 실제 체크/저장하고 시간선을 늘려 초기 범위 이후 조작을 예약했습니다. 초기 임무 표시 시간을 넘겨 비행하며 시간 초과로 종료되지 않고 과거 계획을 다시보기에 유지하는 것을 확인했습니다.
- 마지막 에디터 정리 후 목표 블록/관측 제작 브라우저 검사도 다시 확인했습니다.
- 1920×1080, 1440×1000, 390×844에서 하단 콘솔과 세부 편집창 배치를 검사했습니다. 회전 팝업과 실제 다시보기 캡처를 시각 확인했습니다.
- 7개 로켓 이미지의 불투명 픽셀과 캡슐 일치, 분리 순간 코끝 연속성/운동량, 코끝·옆면·고속 접촉, 반동 중 표면 비관통을 검사합니다.
- 제작용 기준/변형 계획을 배포 JSON에서 제거하는 빌드 플러그인을 검증했습니다. 제작 시험 화면에 정답 불러오기 버튼은 없습니다.
- 기준 경로 8/8 성공, 임의 계획 0/2048, 단순 전략 성공 없음. 예약 제약에 맞는 후보를 검사하며, 금지된 수정 추진이 허용된 엔진 계획까지 제외하지 않도록 회귀 검사를 추가했습니다.
- 대기권·정거장 임무는 서로 다른 첫 출력의 안내 구분이 부족하고, 화성 임무는 풀이 근처 조작이 민감하다는 제작 경고가 남습니다. 단서와 허용 범위는 초심자 플레이 테스트 대상입니다.

검사는 해당 소스와 시드의 유한 표본입니다. 무제한 임무도 audit.timeLimit까지만 검사하며 이후 구간은 미검증입니다. 자동 성공은 모든 경로의 안전성·초심자 난이도·재미의 증명이 아닙니다.

```sh
npm ci
npm run verify
npx playwright install chromium
npm run test:e2e -- --workers=2
# 개발 서버 실행 중:
node scripts/export-rocket-assets.mjs
```

검사 자료와 캡처는 Git에서 제외한 test-results/에, 재사용 이미지/manifest는 public/assets/rockets/에 둡니다. 제작은 /?editor=1, 배포 결과는 dist/입니다. Git clone과 개인 브랜치/PR로 협업합니다. Steam 네이티브 패키징·게임패드·모바일 터치·상대론은 현재 검증 범위 밖입니다.
