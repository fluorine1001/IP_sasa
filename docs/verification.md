# 검증 기록

2026-10-11, IP_sasa의 codex/game-workshop에서 검증합니다.

- TypeScript strict 검사와 Vite 배포 빌드 통과.
- Vitest 80개 통과: 물리·목표·편집·고정 환경의 관측 반복, 네 번의 사전 계획으로 원궤도 해결, 실제 적용 명령과 당시 전체 예약의 격리, 분리 순간 끝 위치 연속성·운동량 보존, 남은 단별 충돌 길이, 코끝·옆면·고속 충돌, 반동 중 전체 몸체의 표면 비관통, 녹화 상태 복원과 재생 범위 제한을 검사합니다.
- Playwright Chromium 26개 통과: 기존 메뉴·제작·저장·스테이지 독립·조준·충돌 흐름에 더해, 타임라인 예약 편집과 비행 중 잠금, 당시 계획을 사용하는 실제 다시보기, 시간 이동·WASD·추적 복귀, 미실행 예약 표시를 검사합니다. 7개 로켓 이미지 상태의 불투명 픽셀이 실제 캡슐 안에 있는지도 1픽셀의 안티앨리어싱 여유로 검사합니다.
- 관제 콘솔 검사에서는 1920×1080·1440×1000·390×844 화면의 하단 패널 높이와 편집창 겹침을 확인했습니다. 예약 메뉴, 빨간 임무 나가기, 최근 발사 바로 재생, 실제 경로 카드 선택을 검사하고 화면을 캡처했습니다.
- capture-experiment.mjs로 대기권 기준 계획을 실제 발사해 성공하고, 2.3·3·5초의 기록을 재생하여 3단·2단·1단 및 분리체를 확인했습니다. 런타임 오류 없음. 다시보기의 투명도·잡음, 진행 바와 편집창 화면도 확인했습니다.
- 원본 기준 경로 8/8 성공, 임의 계획 0/2048, 단순 전략 성공 없음. 현재 플레이 환경은 재시도마다 고정하며 변형을 추첨하지 않습니다.
- 제작 검사에서는 대기권·정거장 미션의 다른 첫 출력에 대한 안내 구분이 부족하고, 화성 미션의 기준 풀이 근처 조작이 민감하다는 경고가 있습니다. 단서와 허용 범위는 추가 초심자 플레이 테스트 대상입니다.

위 수치는 해당 소스와 시드의 유한 표본 결과입니다. 실제 조작·녹화·단 분리·충돌의 회귀를 검증했지만, 모든 임무의 초심자 난이도나 재미를 증명하지는 않습니다.

```sh
npm ci
npm run verify
npx playwright install chromium
npm run test:e2e
# 개발 서버 실행 중:
node scripts/capture-experiment.mjs
node scripts/export-rocket-assets.mjs
```

실패 자료와 화면 캡처는 Git에서 제외한 test-results/에 둡니다. 실제 재사용할 자체 제작 로켓 PNG는 public/assets/rockets/에 저장합니다. 제작 도구는 개발 서버 /?editor=1, 결과물은 dist/입니다.

Steam 네이티브 패키징, 게임패드·모바일 터치 조작, 상대론은 현재 구현/검증 범위에 포함하지 않습니다. 협업은 Git clone과 PR로 진행합니다.
