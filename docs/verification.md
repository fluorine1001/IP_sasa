# 검증 기록

2026-10-11, `IP_sasa`의 `codex/game-workshop`에서 검증합니다.

- TypeScript strict 검사와 Vite 배포 빌드 통과.
- Vitest 73개 통과: 기존 물리·충돌·조준·목표·편집 검사와 동일 실험 재현, 실제 관측만 기록, 세 번의 근거 기반 첫 궤도 풀이, 배속과 무관한 상황 정지, 실제 적용 명령 복사, 관측 메모리 분리, 움직이는 목표 위치 기록, 다른 스테이지에 장면 묶음 붙이기를 검사합니다.
- Playwright Chromium 20개 통과: 메뉴·발사·중력 부표·카메라·종료·기록 보존·블록 제작·JSON 저장·스테이지 독립·조준·충돌·대기권/분리·단서 제작과 첫 퍼즐을 실제 조작 세 번으로 해결하는 전체 흐름을 검사합니다.
- `capture-experiment.mjs`의 실제 브라우저 플레이: 낮음/지나침/그 사이의 발사, 유료 작은 옆 추진, 성공, 실험 카드 3개. 런타임 오류 없음. 지도와 노트 화면을 캡처해 확인했습니다.
- 원본 기준 경로 8/8 성공, 임의 발사 0/2048, 단순 전략 성공 없음. 기존 연구용 변형의 기준 경로도 통과합니다. 현재 플레이에 변형을 추첨하지 않습니다.
- 신규 제작 검사에서 정거장 미션은 일부 시험의 안내가 구별되지 않았고 화성 미션은 기준 풀이 근처 조작에 민감하다는 경고가 있습니다. 고급 스테이지의 단서와 조작 여유는 추가 플레이 테스트 대상입니다. 검사는 이를 숨기지 않고 제작 화면에 표시합니다.

위 수치는 해당 소스와 시드의 유한 표본 결과입니다. 첫 미션은 공식을 사용하지 않는 실제 조작 경로를 검증했지만, 모든 미션의 초심자 난이도나 재미를 증명하지는 않습니다.

```sh
npm ci
npm run verify
npx playwright install chromium
npm run test:e2e
node scripts/capture-experiment.mjs
```

실패 자료와 화면 캡처는 Git에서 제외한 `test-results/`에 둡니다. 제작 도구는 개발 서버 `/?editor=1`, 결과물은 `dist/`입니다.

Steam 네이티브 패키징, 게임패드·모바일 터치 조작, 상대론은 현재 구현/검증 범위에 포함하지 않습니다. 협업은 Git clone과 PR로 진행합니다.
