# 튜토리얼 담당

screen.ts/style.css는 간단한 참고용 비행 안내서, hub.ts/hub.css는 단일 훈련 진입과 별도 완료 기록, lesson.ts/lesson.css는 실제 행동에 따라 바뀌는 상세 실습 안내를 담당합니다. App/Screen은 ../../app/core.ts입니다.

현재 훈련 JSON은 data/stages/34643eaf-0363-4898-b617-63e79ba47d97.json 하나입니다. track=tutorial로 본편과 분리됩니다. 내부 실습 항목은 별개의 레벨이 아니라 같은 비행 세션에서 순서대로 또는 미리 경험할 수 있는 체크입니다. progress.ts의 7개 활동 묶음으로 설명합니다. 행동 체크와 읽는 페이지는 독립이며 완료해도 자동 이동하지 않습니다. 이전·다음·목록으로 이동합니다.

lesson은 반투명 검정 SVG 마스크에 투명한 원을 뚫어 현재 조작 또는 실제 로켓을 강조합니다. 내부를 칠하지 않으며 pointer-events:none으로 실제 조작을 막지 않습니다. 강조는 빠르게 등장한 뒤 투명 원이 화면 밖까지 커지며 사라집니다. 패널은 원 옆으로 빠르게 이동한 뒤 강조 확장과 함께 관제석 위 우측 하단으로 갑니다. 본문 드래그는 관제석 위 배치도 허용하고 최소화·복원합니다. 상세 설명은 고정 내부 스크롤이며 패널 전역의 휠 입력을 처리합니다. 잘린 강조 대상은 먼저 스크롤해 드러냅니다. 실패 때 전체 실습 목록이나 나가기 버튼을 결과 화면에 넣지 않습니다.

기록 탭에서 경로 선택은 점선 표시만 바꾸며 시간이나 비행을 진행시키지 않습니다. 영상은 카드의 재생 버튼으로만 실행합니다. 재생 뒤 ‘비행 화면으로’로 돌아오고, 결과 화면에는 다시보기나 훈련소 복귀 버튼이 없습니다. 남은 조작은 기존 실습 안내에서 계속 진행합니다.

flight/screen.ts는 실제 예약 편집, 일시정지, 단 분리·재점화·회전·관성 비행, 녹화 탐색, 기록 복사, 한 변수만 바꾼 발사, 두 결과 비교, 물리 목표 달성을 전달합니다. lesson은 UI 상태만 보유하고 물리를 바꾸지 않습니다. 목표 달성만으로 완료되지 않으며 목표를 먼저 달성한 경우에도 이후 재생·비교로 완료할 수 있습니다.

상세 가이드는 PlayArgs.tutorial=true인 진입에서만 작동합니다. 제작 에디터에서 훈련 JSON을 시험할 때는 물리 목표만 검사하여 저자가 기준 계획을 저장할 수 있습니다. 완료는 orbit-tutorial-completed-v1에 저장하며 본편 완료 키와 공유하지 않습니다.

조작·아이콘·기록 읽는 법을 설명하며 특정 미션의 정답 시각/출력/경로는 제공하지 않습니다. 출력·회전은 값 편집, 분리·끄기는 이동/삭제입니다. 원래 분할된 훈련 4개는 새 UUID의 단일 훈련으로 교체했습니다. 이전 완료 ID는 새 훈련 완료로 간주하지 않습니다.

CSS는 .help-grid/.control-card 또는 자체 클래스에 제한합니다. 이벤트는 AbortController/dispose로 정리합니다. 다른 화면·물리 import는 check:boundaries에서 거부합니다. 화면 전환과 실제 조작을 확인해 PR에 기록합니다.
